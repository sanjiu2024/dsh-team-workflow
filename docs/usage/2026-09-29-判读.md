- **瓶颈在模型侧**：模型等待 73,103,081ms，占步墙钟 **86.9%**（工具执行 11,067,101ms 占 13.2%，其他 19,748ms 占 0%）。

- 步墙钟 p50 17,237ms → p90 49,502ms → p99 176,352ms，长尾明显偏离中位——少数超长步贡献了不成比例的时间。

- 最慢 10 步拆开看是三种慢，别混成一类：
  - **等人**（3 步，`ask_user_question` 850,474 / 600,570 / 355,798ms）——墙钟在等用户回答，不是性能问题；
  - **本地长命令前台干等**（1 步：session-8bc298… turn 30/113，`bash` 600,570ms）——这条本可后台化；
  - **纯模型生成慢**（6 步，模型等待 673,903 / 581,858 / 509,602 / 457,605 / 434,399 / 407,618ms）——
    其中 5 步 prompt 只有 29,884 ~ 67,570 tokens，慢在生成不在上下文；
    例外是 session-8bc298… turn 40/22，prompt 232,434 tokens、墙钟 417,208ms，这条确实被大 prompt 拖慢。
