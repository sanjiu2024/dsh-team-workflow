# REQ-019 · 角色档位降级链（修 `roles.审查` → tier-power 503）

- 状态：已完成（2026-10-16）
- 版本：`2.1.0`
- 关联：[REQ-016](REQ-016-小队2.0.md)（角色档位 D3）、[REQ-017](REQ-017-squad状态机可审查化.md)（本轮独立测报出的环境前提）

## 1. 要做什么

`roles` 表里的档位值，除了字符串，**还可以是一个数组** —— 按顺序试：

```jsonc
"roles": {
  "审查": ["tier-power", "tier-std"]   // 优先用强的；网关没这条渠道就退到下一个
}
```

换档必须**看得见**：过渡时结论栏写「换档重试（A → B）…」，跑完并进最终结论
「收工（N 步，…；中途换档 A → B）」。

出厂默认：`team/extensions/squad.json` 的 `审查` → `["tier-power", "tier-std"]`。

## 2. 不做什么

- **不做「自动探测网关有哪些档」**：包这边查不到网关的渠道表，探测就得发请求，
  而发请求本身就会失败 —— 那是拿用户的钱去猜。链是**配置**，不是探测。
- **不改 `roleModel` 的语义**：它仍返回链上第一个（8 个调用点不用动）。
  要整条链的地方只有「起一轮」那一处。
- **不做「降级到别的 provider」**：只换 `model`，provider 不动（换 provider 是另一件事，
  涉及鉴权与配额，不在本需求里）。
- **不静默**：不写「悄悄用了备用档」这种实现。换档一定要出现在成员结论栏里。

## 4. 已知约束（动笔前查到的硬事实）

- **`roles` 的解析有 8 个调用点**（`lib/squad.js` 的 1372/1434/1598/1658/1659/1781/1875/1978），
  全都走 `roleModel` → 所以「链」必须做成**加法**（新函数），不能改 `roleModel` 的返回类型，
  否则 8 处一起要改。
- **「起一轮」只有一处**：`lib/squad-round.js` 的 `startMember`（REQ-017 刚把它拆出来）→
  换档逻辑放这一处，不用碰 8 个调用点。
- **重试机制已经存在**：`for (let attempt = 1; attempt <= retries + 1; ...)`，只对 `kind === "infra"`
  重试 → 换档挂在「第 N 次用链上第 N 个」上，天然复用。
- **校验器现状**（`lib/squad.js` 的 `roles:`）：只接受字符串，坏条目**整体拒**（这个语义要保留）。

## 5. 方案

1. `lib/squad.js`：新增 `roleModelChain(roles, role)`（唯一真相源，滤空、归一「型」），
   `roleModel` 改成 `roleModelChain(...)[0]`；校验器接受 `string | string[]`，
   数组里有坏条目（非字符串 / 空串 / 空数组）整体拒。
2. `lib/squad-round.js`：`startMember` 里算出 `tierChain = [主档, ...roles 链里其余的]`，
   重试第 N 次用 `tierChain[min(N-1, len-1)]`；换档时记 `tierNote`，收尾并进 `note`。
3. `team/extensions/squad.json`：`审查` 改成链 + 把 `_help` 里那条「网关得有这条渠道」的
   警告改成说明链的用法。
4. `deps` 多一个键：`roleModelChain: (role) => roleModelChain(config.roles, role)`。

## 6. 天花板

- 链只在**同一 provider 内**换档；provider 不通就还是失败。链里**只能写 model 别名**
  （写 `new-api/tier-power` 这种会被原样当 model 传出去，全仓没有 `split("/")` 解析）。
- 换档靠的是**重试预算**（`limits.retries`，默认 1）—— 链比 `retries + 1` 长时，后面那些档
  **这一轮用不上**，而且下一轮 `attempt` 又从 1 重数，所以是**永远用不上**（独立测实测）。
  换句话说：**链长超过 `retries + 1` 的部分是死配置** —— 配的时候别写超过 `retries + 1` 条。
  要真的试更多档，就把 `limits.retries` 调大（代价是多花模型调用，那是用户的选择，不偷偷加）。
- 探测网关渠道表仍然做不到（见 §2）。

### 实现过程中踩到并修掉的

- **换档信息被收尾分支盖掉**：过渡时写的「换档重试…」在跑完之后被 `收工（N 步…）` 覆盖 ——
  那就是**静默换档**。改成把换档事实并进最终结论（测试一开始断言的是过渡措辞，也一并纠正）。
- **出厂 JSON 被插坏**：往 `team/extensions/squad.json` 的 `_help` 里写带引号的示例时转义出错，
  文件直接不是合法 JSON（自检当场逮到）。
- **改 schema 要连带改钉住 schema 的测试**：两条断言原本写死 `roles.审查 === "tier-power"`，
  改成 deepEqual 数组。
