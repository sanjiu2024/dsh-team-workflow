## 2. 为什么（不做的后果）

- **收不住**：一个成员跑飞只能连坐整队（A1）；烧 token 的唯一刹车是步数与 20 分钟墙钟（A2）；一次派 10 个就是 10 条 loop 同时打网关（A3）。
- **隔离是软的**：成员的 `bash` 沙箱档位取**宿主当前策略**，本会话是 `danger-full-access` —— 也就是说成员能写到 worktree 外面（A4）。这条一直没写进文档，用户以为有隔离。
- **协调全靠主 agent**：成员之间不能等、不能汇合（A6）；「每块产出必须有人审」只是系统提示里的规范，主 agent 忘了派就没人派（A7）。
- **重启就降级**：转录被压缩（B1）、`inbox`/`history` 不落盘（B2）、同 cwd 双进程互相覆盖（B5）。
- **看不见**：面板只有快照（B3）；命令行看不到小队（B6）；成本只有会话视角、成员调用算不进去（C1/C2）。
- **发版会漏**：13 个版本从没打过标签，就是没有守卫（D1）。

## 3. 不做什么

**用户这次没勾的（明确不做）**：

- **A5 成员嵌套** —— 成员不能再派成员，小队仍然只有一层
- **B4 面板写操作** —— 面板保持**只读**（加写路由要碰信任边界，没勾就不碰）
- **C3 价目表 / 算钱** —— 仍然只有 token，算不出钱（需要用户给单价）
- **D2 反向实验自动化** —— 反向实验继续手工跑（结果记进 §8）

**既有天花板不变**（REQ-015 §7 的继续有效）：

- 成员不能 `merge`/`drop` worktree、不能 `push`、不能改小队状态
- 成员不占 dsh 会话列表、成员的模型调用不算进会话账单
- 不引入**任何 npm 依赖**（零依赖是这个包的底线）
- 不做跨机器状态同步（B5 只解决本机跨进程）

## 5. 已知约束（侦察出来的硬事实）

> 三路调研（2026-10-16）：①dsh 插件实时推送能力 ②跨进程锁 + usage 数据源 ③19 项落点。
> 下面每条都是**查到的**，不是印象。

| 约束 | 证据 | 影响 |
| --- | --- | --- |
| **宿主原生支持 SSE**（handler 持有完整响应生命周期），且有投产先例 | `dsh-host-webserver/lib/types/index.d.ts:90`（注释原文提 SSE）、`dsh-client-hmr/lib/index.js:145` + `lib/client.js:64`（`/plugins/events` + `EventSource`） | **B3 走 SSE**，不用宿主配合。WS 那条（`/api/remote.mux`）要生成描述符、且 `registerRemoteEvents` 是单所有者，插件抢不到 |

## 6. 方案

> 从 §5 的事实出发。**分五块**，块 1 是其余所有项的落点。

### 块 1 · 配置底座（E1 + D3）—— 已实现

- 新增 `lib/squad-config.js`：`SQUAD_CONFIG_VERSION`、`SQUAD_CONFIG_GROUPS`、`flattenSquadConfig(raw, warn)`
  （**纯函数**，把 v1 扁平 / v2 分组 / 两者混着压成一层）。
- `readJsonConfig` 加**可选** `normalize` 参数（`lib/util.js`），`layered` 透传（`lib/index.js`），
  **只有 squad** 那一行传 —— 不做全局钩子（§5 那条）。
- `team/extensions/squad.json` 升 v2：`configVersion: 2` + `defaults{provider,model}` +
  `limits{maxSteps,retries,memberTimeoutMinutes}` + `sandbox{bash}` + `roles{...}`。
- **为什么不写回文件**：包目录可能只读；运行时改用户的源码文件是意外行为。v1 照常读进来，只在日志提示一次。
- **D3**：`roleModel(roles, role)` 纯函数（查表前把尾部「型」去掉 —— 否则「审查」与「审查型」落到两条路上）；
  `squad_spawn` 不传 `model` 时按角色取；成员把**实际用的档位**记在自己身上（`model`/`provider`），
  落盘/还原/快照都带上，`squad_send` 续聊沿用 —— 否则「审查型配了 tier-power，续聊掉回 tier-std」没人查得出来。

### 块 2 · 可控性（A1/A2/A3/A4）—— 已实现

- **A1 `squad_stop`**：只掐**一个**成员（`member.running.abort.abort()`），同队其他人照跑；
  掐完自己写 `status`/`note` 再落盘（`running` 是运行时字段、不进快照）。
  两个细节是必须的：① 不能用整队的 `abortMembers`（那是收队/拆除用的，会把别人一起掐掉）；
  ② 停止原因要先存进 `member.stopNote`，因为循环收尾会用「被中止」覆盖 `note` ——
  不存的话工具答应「写了原因」而实际被吃掉。
- **A2 预算**：`limits.tokenBudget` 与 `limits.memberTokenBudget`（0 = 不限），取**更紧**的那个。
  **在步边界判**（只在收工判的话一步就能超出去一大截），队级的账跨成员累加。
  超了判「卡住」+ 原因写明是预算 —— **不是「完成」**（活没干完），也**不重试**（重试等于继续烧）。
  用量口径单独抽了 `usageTotalOf()`：优先 provider 给的 `totalTokens`，没有就把各项加起来
  （dsh 的各项是互斥的，`inputTokens` 只是未命中缓存的那部分）。**不假设 provider 一定给总量** ——
  第一版只认 `totalTokens`，假流不给就永远不触发（反向实验 R5 现在守着这条）。
- **A3 并发**：`limits.maxRunning`（0 = 不限）。超了就**排队**（名册行先建好、不跑），
  有人收工自动补位。补位挂在成员 promise 的 **`finally`** —— 挂 `then` 的话异常路径不补位，
  队列永久堵死。重启时「排队」判「卡住」并说明「重启后不会自动补位，再 spawn 一次」。
- **A4 角色白名单**：`sandbox.roleTools`（角色 → 允许的工具名，空表 = 不限制）。收窄点在
  `memberToolsFor({bash, allow})` **一处**，`schemas` / `allowed` / 提示词里的 toolNames
  都由它派生（漏一处 = 说给不到其实能调）。与 `bash` 那道全局闸门是**「与」**：
  白名单里写了 `bash`、但全局关着，它也拿不到。
  **这不是沙箱**：最终强度仍由宿主策略决定（`danger-full-access` 下等于没有），
  这条天花板已补进 REQ-015 §7。

### 块 3 · 协作（A6/A7/A8/A9/A10）—— 已实现

- **A8 结构化回报**（先做，A7 要用它）：新模块 `lib/squad-report.js`，`parseReport()` 认
  `## 交付物` / `**证据**：` / `- 没做的：` 这类小标题（每个键认几种别名），压成四段。
  **模型自报不可靠**：一个都没认出来就 `parsed:false` + 原文留着 —— 不编、不塞进「交付物」里。
  收工时代理黑板写的是**摘要**（`formatReport`），全文还在转录里；成员提示词里写死了这四段。
- **A10 验收清单**：小队级 `acceptance`（`squad_new` 建队时给、`squad_update` 改），
  成员用 `check` 工具勾（序号或文字开头都认）。**勾过的记「谁勾的 + 怎么验的」**，
  第二个人再勾同一条会被拒（谁验的不能被顶掉）；勾了就落盘 + 上黑板。
  `reviveSquad` 给默认 `[]`（旧文件没有这个字段）。
- **A9 模板**：`templates`（名字 → 成员骨架）**落配置**，不硬编码 —— 改分工不该需要发版。
  `squad_new({template})` 建队 + 按模板派（受 `maxRunning` 约束，超了排队）。worktree 允许相对
  小队 cwd 的路径；**目录还不存在的条目不进名册**（免得成员一上来就 fs 报错白烧一轮），
  回复里列出来让你先 `worktree_new`。
- **A6 等待**：**不做阻塞等待**（成员侧阻塞就是死锁）。成员用 `wait` 工具挂号 → 自己掐停这次
  （`stopSelf`）、状态判「等待」；目标收工时由 `wakeWaiters` 把它叫回来
  （`startMember({resume})`，把**对方的结论/回报**当新任务投进去）。目标已经收工就当场把结论给它、
  不挂起；等自己 / 等不存在的人 / **等成环**（顺着 `waitingFor` 走一圈能回到自己）一律拒。
  叫醒挂在成员 promise 的 `finally`（与补位同一处）—— 挂 `then` 的话异常路径上等待的人永远醒不来。
- **A7 `squad_review`**：起一个审查型成员（角色表里「审查」那一档）审指定成员的产出。
  被审者必须**已收工**（还在跑 / 没做完都拒 —— 审半成品只会得到半成品的结论）。
  审查成员是**独立循环**、读不到被审者的 `transcript`（内存态），所以这个工具把被审者的
  回报 + worktree + 小队验收清单 + focus **塞进它的 task**，并写死边界（「只审这一个成员，
  不要全仓探索」「只审不改」）。结论挂回**被审者那一行**（`review`），`squad_status` 显示「已被 X 审」。
