## 1. 要做什么

小队面板（Web GUI 侧栏「小队」）现在能看队、看成员、看黑板，但队一多就得靠肉眼翻。要加三样：

1. **搜索过滤**：一个输入框，按**队名 / 成员名 / 角色 / 成员名册里的任务**筛卡片，边打边过滤。
2. **耗时列**：成员行显示「入队到现在」的耗时（如 `12m`、`1h20m`），让人一眼看出谁挂了太久。
3. **会话标题**：成员行显示它那个会话的标题，而不是只有一串 `agentId`。

原始诉求是「成本列」，但成本要先看有没有数据来源（见 §3、§5）——**没有就降级成耗时**，
不硬造。

## 2. 为什么（不做的后果）

- 小队数量没有上限（用户明确要的：不设上限），三个队以上就要滚动找；搜索是省时间的第一件事。
- 成员卡住时面板上看不出来 —— 状态是「在跑」但不知道跑了多久，耗时列是唯一能从现有数据
  算出来的信号。
- 会话标题是「点进去看这个成员在干嘛」的路标；只有 id 时，人得逐个点开才知道谁是谁。

## 3. 不做什么

- **不加任何写路由**。面板保持只读（REQ-009 §6.2 的约定）：所有改动仍只走 6 个进程内工具
  + `authorize()`。搜索是纯客户端过滤，不进服务端。
- **不做成本/token 列**（除非侦察证明有可验证来源且不需要新开宿主 API）。要不到就只做耗时。
- **不改小队的身份与权限模型**（`authorize` / `agent_id` 仅所有者 / 收队只读）—— 一行都不碰。
- **不做跨会话持久化**（小队仍是进程内内存，REQ-009 §7 的边界不变）。
- **不做服务端搜索/分页**：队数量是「几十」量级，客户端过滤够用；服务端分页要动路由与
  协议，不值当。
- **不显示成员的历史耗时曲线 / 成本趋势** —— 没有数据源，也不属于这次的三样。

## 6. 方案

从 §5 的事实出发（不是从印象）：

**服务端（`lib/squad.js`，唯一要动的一处）**
- `addMember` 的成员对象（`:221-230`）加 `createdAt: Date.now()`；`squadView` 的成员映射（`:348`）
  透出它。**不改** `updatedAt` 的语义（它是「最后一次改动」）。
- 不动路由：`GET /squads` 的响应形状不变，只是成员多一个字段。

**客户端（`lib/client.js`）**
- 抽出两个**纯函数并导出**，让自检能直接断言（不靠渲染）：
  `exports.squadMatches(query, squad)` —— 命中队名 / 成员名 / 角色 / 成员任务，大小写不敏感，
  空查询恒真；`exports.formatDuration(ms)` —— `<1min` → `刚刚`、`<1h` → `Nm`、`<1d` → `Nh Mm`、
  更久 → `Nd`。
- 过滤插在 `:775`（`const squads = data?.squads ?? [];`）**之后**，过滤源数组一处生效；
  必须同时**重算 `current`**：`selected` 落在被滤掉的队上时回落到过滤结果第一条，
  结果为空时渲染空态（不能沿用 `:779` 的 `?? squads[0]` —— 那会展开一个用户没在看的队）。
- 搜索框放卡片列表（`:899`）上方：受控输入 + 本地 `useState`，不进服务端、不进 URL。
- 成员行（`memberBlock` `:820-849`）加两样：耗时（`Date.now() - createdAt`，用 `formatDuration`）、
  会话标题（`useSessions().byId[agentId]?.displayTitle ?? agentId`）。
- 标题的取法有**同槽先例**可抄：`dsh-client-ui-schedule` 在 `main` 槽用
  `Pick<PropsRuntime<'main'>,'useSessions'>`（`lib/client.js:3555-3556`）。我们面板也注册在
  `main` 槽（`:933` / `:981`），所以 `useSessions` 可用。

**为什么不选别的路**
- 不做服务端搜索/分页：队数量是「几十」量级，客户端过滤够用；分页要动路由与协议，不值当。
- 不做「成本」列：`dsh-token-meter` 只有 image/file 的 **token** 定价启发式，全链路
  `cost/price/currency` 零命中 —— 要显示钱就得自造单价表，等于新造一层未验证定价。
- 不做「在 `squad_add` 里手填标题」：`useSessions` 免费且自动，手填会立刻过期。

**已知的不确定项与处置（写清楚，不装确定）**
- `useSessions().byId` 里**是否稳定包含 subagent 会话**没有实测（侦察-A 明确说它没实测，
  只有 `origin?: 'subagent'` 与 retained-subagent fallback 两条形状线索）。方案按
  「取不到标题就回退显示 `agentId`」写 —— 那正是现在的行为，所以最坏情况**不退化**。
  收尾时在浏览器里确认；若确认拿不到，把这一条降级进 §7。
